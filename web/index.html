03

Личные ключи

Создайте две пары ключей

Одна пара нужна для шифрования, другая — для подписи. Закрытые ключи сохраняются только в этом браузерном профиле. Сервер получает открытые ключи и проверяет два действия с одноразовыми заданиями.

04

Сертификаты

Проверьте учебный CA

После проверки личных ключей запросите отдельные сертификаты для шифрования и подписи. Сверьте SHA-256 отпечаток корня с контрольным значением, которое преподаватель сообщил отдельно от этой страницы.

Сначала подтвердите владение личными ключами.

Отпечаток, показанный самой страницей, не служит независимым контрольным значением. Закрытый ключ CA остаётся на сервере.

05

Цифровая подпись

Сравните три проверки

Сервер выдаёт один текст на пять минут. Подпишите его личным ключом, затем временным ключом и, наконец, проверьте личную подпись после изменения одного символа. Временный закрытый ключ не сохраняется.

1. Личный ключ

Подпись должна пройти проверку открытым ключом из вашего сертификата подписи.

Ожидается исходный текст.

2. Другой ключ

Временная подпись верна для временного открытого ключа, но не для ключа в вашем сертификате.

Ожидается временный ключ.

3. Изменённый текст

Проверьте прежнюю личную подпись для текста, в котором изменён ровно один символ.

Ожидается личная подпись.
Сначала подтвердите сертификаты.

Сервер самостоятельно повторяет все проверки и засчитывает шаг только при трёх корректных опытах.

06

Пакет серверу

Зашифруйте своё сообщение

Получите сертификат серверного участника, изучите его и введите короткий учебный текст. Браузер создаст отдельный ключ AES и пакет JSON. Сервер расшифрует пакет как адресат и сохранит только его хеш.

Сначала завершите упражнение с подписью.
07

Пакет от сервера

Расшифруйте ответ

Сервер зашифрует одноразовый секрет для открытого ключа из вашего сертификата. Расшифрование выполняется только в браузере личным закрытым ключом.

Сначала отправьте пакет серверу.

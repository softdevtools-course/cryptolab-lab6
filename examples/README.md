# Публичные материалы ЛР №6

Файлы в этом каталоге доступны для ручного упражнения на
[стенде CryptoLab](https://lab-06.course.denrad.dev/):

| Файл | Для чего нужен |
| --- | --- |
| [`training-key.pem`](training-key.pem) | Намеренно открытый учебный **закрытый** ключ для первого расшифрования. |
| [`wrong-key.pem`](wrong-key.pem) | Другой учебный закрытый ключ: расшифрование того же текста должно завершиться отказом. |
| [`ciphertext.txt`](ciphertext.txt) | Шифротекст для сравнения двух ключей. |
| [`ca-cert.pem`](ca-cert.pem) | **Открытый** корневой сертификат CA, работающего на стенде. |

Скопируйте содержимое `training-key.pem` и `ciphertext.txt` в первый блок
стенда, расшифруйте текст, затем повторите попытку с `wrong-key.pem`.
Публикация обоих учебных закрытых ключей преднамеренна: ими нельзя защищать
настоящие данные. Одноразовое задание после этого шага сервер создаёт отдельно.

Для проверки сертификатов откройте `ca-cert.pem` и сравните его отпечаток SHA-256
с отпечатком сертификата, показанным на стенде, и контрольным значением,
сообщённым преподавателем:

```text
EE:6B:54:26:B1:39:E6:B8:B1:69:59:29:6C:A0:5D:5D:C7:68:0D:07:8B:B9:FE:34:C5:F5:1E:86:B6:38:68:EC
```

При переиздании CA этот файл и контрольный отпечаток нужно обновить вместе.
Это учебный CA; не добавляйте его сертификат в системное хранилище доверия.
Закрытые ключи CA, серверного участника и студентов в GitHub не размещаются.
